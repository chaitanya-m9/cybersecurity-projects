# Viva Questions & Answers — Text Encryption Tool

## Q1. What is the objective of the project?
**Answer:** Text Encryption Tool demonstrates a focused cybersecurity concept through a small, reproducible defensive application.

## Q2. Why was Python selected?
**Answer:** Python provides readable syntax and standard libraries/packages that make cybersecurity concepts easy to demonstrate and test.

## Q3. What is the main security concern?
**Answer:** The implementation must protect sensitive data, validate input, fail safely, and remain within authorized educational use.

## Q4. What are the major limitations?
**Answer:** This is an educational implementation, not a replacement for enterprise security products. Real environments require stronger controls, monitoring, testing, and operational processes.

## Q5. How would you improve it?
**Answer:** Add automated tests, structured logging, configuration, stronger error handling, a user interface where appropriate, and production-grade security controls.

## Q6. How did you test the project?
**Answer:** Tests cover normal inputs, boundary cases, invalid inputs, failure conditions, and security-specific cases relevant to the project.

## Q7. What ethical precautions are required?
**Answer:** Use only synthetic data and systems you own or are explicitly authorized to test. Never expose credentials, keys, private logs, or other sensitive information.

## Q8. What skills does this project demonstrate?
**Answer:** Python programming, secure coding, testing, documentation, cybersecurity fundamentals, troubleshooting, and Git/GitHub workflow.
