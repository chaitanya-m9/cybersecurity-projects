# Project Summary

## Author
Chaitanya Mediboyina — https://github.com/chaitanya-m9

This repository contains six cybersecurity projects demonstrating programming, secure coding, cryptography, endpoint defense, network fundamentals, and security monitoring.

### 01 — Password Strength Checker
Local password-quality assessment using length, character diversity, common-password detection, predictable-pattern checks, and entropy estimation.

### 02 — Text Encryption Tool
Fernet authenticated encryption demonstration for protecting text and teaching symmetric-key handling and integrity validation.

### 03 — Image Encryption Tool
AES-GCM binary-file encryption demonstration that protects image bytes and supports byte-for-byte recovery verification.

### 04 — Safe Keylogger Monitor
Defensive filesystem monitoring for synthetic keylogger indicators. It intentionally does not capture keyboard input.

### 05 — Network Scanner
Bounded TCP connectivity scanner for authorized labs, demonstrating sockets, timeouts, port ranges, and asset discovery.

### 06 — Log / SIEM Analyzer
Authentication-log analyzer that parses failed-login events, aggregates source IPs, and generates threshold-based alerts.

## Evidence Included
Each project contains source code, README documentation, architecture material, project reporting, implementation guidance, and tests. Demonstrations use synthetic data and authorized-lab boundaries.
