# Resume Project Descriptions

**Author:** Chaitanya Mediboyina  
**GitHub:** https://github.com/chaitanya-m9

## Password Strength Checker
Developed a Python password-security analyzer that evaluates length, character diversity, common-password patterns, repeated characters, and estimated entropy without storing passwords.

## Text Encryption Tool
Built an authenticated symmetric-encryption utility using Python cryptography/Fernet, demonstrating encryption, decryption, integrity validation, and safe key-handling practices.

## Image Encryption Tool
Implemented AES-GCM based binary/image encryption with nonce handling, authenticated decryption, and SHA-256 based recovery verification.

## Safe Keylogger Monitor
Developed a defensive monitoring utility that scans an authorized directory for synthetic keylogger filenames and code indicators, hashes findings, and generates a JSON detection report without capturing keystrokes.

## Network Scanner
Implemented a bounded TCP connectivity scanner using Python sockets, configurable port ranges, and timeouts for authorized asset-discovery labs.

## Log / SIEM Analyzer
Created a Python security-log analyzer that parses failed-login events, aggregates activity by source IP and username, and generates threshold-based alerts for analyst review.

## Portfolio Skills
Python, secure coding, cryptography, authentication security, endpoint monitoring, TCP networking, log analysis, detection engineering fundamentals, testing, Git, and GitHub documentation.
