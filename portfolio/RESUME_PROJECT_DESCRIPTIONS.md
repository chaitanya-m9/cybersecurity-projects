# Resume Project Descriptions
- **Password Strength Checker:** Python utility using entropy estimation, character-class analysis, and common-password detection.
- **Text Encryption Tool:** Local authenticated encryption utility using Fernet with key generation and error handling.
- **Image Encryption Tool:** AES-GCM confidentiality/integrity protection for image bytes.
- **Safe Keylogger Monitor/Detection:** Defensive endpoint monitor identifying suspicious keylogging filenames and code indicators without capturing keystrokes.
- **Network Scanner:** Authorized-lab TCP connect scanner for identifying reachable ports without exploitation.
- **Log/SIEM Analyzer:** Lightweight SIEM-style parser aggregating failed authentication events by source IP and username with threshold alerts.
